  track3_scholarships.csv
or:
  track3_scholarships (1).csv

When served over HTTP (e.g., Live Server, npx serve, GitHub Pages, or backend SERVE_FRONTEND=true),
ScholarFinder AI automatically checks this folder for the CSV dataset on startup.

You can also upload the CSV file directly in the website UI at any time without placing it here.
